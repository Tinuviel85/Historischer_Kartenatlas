Über den Kartenatlas

Der historische Kartenatlas zeigt ausgewählte historische, georeferenzierte Karten über aktuellen OpenStreetMap-Kacheln. Die Karten werden direkt von den in dieser HTML-Datei hinterlegten externen Anbietern geladen.

Hinweis für iPhone/iPad: Beim direkten Öffnen aus Dateien in Edge (edge://external-file) kann der Browser externe Skripte blockieren. Für den zuverlässigen Betrieb die index.html über HTTPS, beispielsweise GitHub Pages, aufrufen. Kartenkacheln benötigen weiterhin Internet.

Bedienung: Eine Karte aus der Bibliothek auswählen, ihre Deckkraft einstellen oder unter „Vergleichen“ die Trennlinie verschieben. Die Zeitleiste wechselt zwischen datierten Karten derselben Region. Über die Suche lassen sich heutige Adressen ansteuern.

Die automatische Positionierung nutzt ungefähre Regionsmittelpunkte, keine geprüften Kartengrenzen. Einige alte externe Kachelserver können nicht mehr erreichbar sein; die Quelladressen wurden bewusst unverändert übernommen. Bei historischen Karten können unkartierte Flächen transparent bleiben.

Favoriten werden ausschließlich lokal in diesem Browser gespeichert. Der Standort und optional die Kompassrichtung werden erst auf Knopfdruck angefragt. Die Kompassanzeige kann auf iOS eine zusätzliche Sensorfreigabe benötigen. Ein geteilter Link kann den gerade sichtbaren Kartenausschnitt und damit auch eine Standortposition enthalten.
